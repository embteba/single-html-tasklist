# single-html-tasklist
単一HTMLで動作するタスク管理ツール

## 概要

`index.html` 1ファイルのみで動作する、マインドマップ型タスク管理 + ガントチャートツールです。
HTML / CSS / JavaScript はすべてこのファイル内に閉じており、CDNや外部通信は一切使用しません。
`file://` で直接ブラウザに開くだけでオフライン動作します。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge 等）で直接開きます。
2. 左側の「マインドマップ」でタスクをツリー状に作成します。
   - ルートノードから「＋ 子ノードを追加」で子・孫ノードを追加できます。
   - ノードをクリックすると右側の詳細パネルで名前・開始日・終了日を編集できます（ルートノードは日付設定不可）。
   - ノードはドラッグで自由に配置できます。
3. 子・孫ノードに開始日と終了日の両方を設定すると、右側の「ガントチャート」に自動でバーが反映されます。
4. ガントチャート側でもバー本体をドラッグして期間を移動、バー両端をドラッグして開始日・終了日を個別に変更できます（マインドマップ側にも同期されます）。
5. 日程未設定のタスクは「未日程タスク」カードとして表示され、日付グリッドへドラッグ＆ドロップすると1日分のバーとして日程が確定します。
6. ガント表示期間は固定長（180日）のウィンドウで、「前の期間 / 次の期間 / 今日」ボタンで任意の時期へ移動できます（極端に離れた日付を読み込んでも表示が固まらないようにするための設計です）。

## 保存仕様（Import / Export）

- 「Export (JSON)」でプロジェクトの全データ（プロジェクト名・ノードツリー・日付・配置座標）をJSONファイルとしてダウンロードできます。
- 「Import (JSON)」で、エクスポートしたJSONファイルを読み込み、状態を復元できます。
- インポート時はJSON構文・スキーマ（ルートノードの一意性、親参照の整合性、循環参照の有無、日付形式など）を検証し、不正な場合はエラー内容を表示して現在の状態を変更しません。
- ブラウザの `localStorage` が利用可能な場合は自動保存されますが、`file://` 環境など localStorage が使えない場合は自動保存が無効になる旨を画面上部に表示します。その場合も Export による手動保存は常に利用できます。
- JSONのスキーマ例:
  ```json
  {
    "schemaVersion": 1,
    "project": { "name": "プロジェクト名" },
    "nodes": [
      { "id": "n1", "parentId": null, "name": "ルート", "start": null, "end": null, "x": 40, "y": 260 },
      { "id": "n2", "parentId": "n1", "name": "タスクA", "start": "2026-01-01", "end": "2026-01-05", "x": 260, "y": 260 }
    ]
  }
  ```
